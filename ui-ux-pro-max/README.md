# UI/UX Pro Max - Design Intelligence Skill

A comprehensive design intelligence skill from [nextlevelbuilder](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) that provides AI coding assistants with a searchable database of UI styles, color palettes, font pairings, chart types, UX guidelines, and stack-specific best practices.

## Stats
- **72K+** GitHub Stars
- **138K+** Installs
- **67** UI Styles
- **161** Color Palettes
- **57** Font Pairings
- **25** Chart Types
- **99** UX Guidelines
- **16** Tech Stacks

## What It Does

The skill prescribes a 4-step workflow:

1. **Analyze** — Extract product type, style keywords, industry, and tech stack
2. **Search** — Use `scripts/search.py` across multiple design domains
3. **Generate** — Synthesize results into a design system
4. **Apply Stack Guidelines** — Framework-specific best practices

## Installation

```bash
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
```

Or via npx:
```bash
npx skills add nextlevelbuilder/ui-ux-pro-max-skill
```
